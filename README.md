## 项目简介

本站收录了缠中说禅先生在不同领域的主要著述，按主题分为以下几个核心板块：

- **文史哲学**：《论语》详解 —— 以禅宗视角重新解读儒家经典
- **禅修实修**：禅与坐 —— 打坐入门、生死之学、唯识要义
- **佛教哲学**：唯识宗到禅宗 —— 八识、三性、转识成智的层层深入
- **中医经方**：伤寒金匮方剂全集 —— 仲景医学的现代整理

所有页面均采用统一的古典中文风格，使用楷体字体，配以红黑主色调，
力求在视觉上接近传统线装书的阅读体验。

## 内容版块

### 一、《论语》详解

- **路径**：`论语详解.html`
- **来源**：缠中说禅先生《论语》详解系列博文
- **结构**：按《论语》原文章节顺序逐句解读
- **特色**：每章包含原文、现代汉语翻译、禅宗视角的解读

### 二、禅与坐

- **路径**：`禅与坐.html`
- **内容**：打坐基础、生死之学、唯识要义、呼吸法门等
- **章节数**：约 38 节
- **特色**：兼顾理论（唯识学）与实修（打坐方法）

### 三、唯识宗到禅宗

- **路径**：`唯识宗到禅宗.html`
- **内容**：以"对话体"形式展开 22 个核心问题
- **特色**：
  - 涵盖八识理论、三性三无性、种子六义等核心概念
  - 对话形式层层递进，符合"教理—实修—印证"的认知规律
  - 配备左侧目录导航，支持移动端浮动按钮弹出

### 四、伤寒金匮方剂全集

- **路径**：`伤寒金匮方剂全集.html`
- **内容**：仲景经方的完整整理
- **来源**：`图片/` 目录下的 64 张原始图版
- **特色**：忠实还原方剂原貌

## 技术栈

| 项目 | 选型 |
|------|------|
| **架构** | 纯静态 HTML / CSS / JavaScript |
| **样式** | 原生 CSS3（无框架） |
| **字体** | 系统楷体 / 思源宋体（Noto Serif SC） |
| **响应式** | CSS Media Queries（1080px / 768px / 420px 三档断点） |
| **交互** | 原生 JavaScript（无 jQuery / 无框架） |
| **图标** | SVG |
| **后端** | 无（可任意静态托管） |

**设计原则**：

- 零依赖 —— 双击 HTML 即可在浏览器打开
- 离线优先 —— 所有内容都在本地，无外部 API
- 阅读优先 —— 无广告、无追踪、无统计

## 本地预览

### 方法一：直接打开

直接双击 `index.html` 即可在浏览器中打开。

> 注意：部分浏览器对 `file://` 协议下的相对路径有同源限制，
> 遇到样式加载异常时请使用方法二。

### 方法二：本地 HTTP 服务器（推荐）

```bash
# 进入项目目录
cd d:\AI\solo\缠中说禅

# Python 3 内置 HTTP 服务器
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后在浏览器访问：

- 主页：<http://localhost:8000/>
- 论语详解：<http://localhost:8000/论语详解.html>
- 禅与坐：<http://localhost:8000/禅与坐.html>
- 唯识宗到禅宗：<http://localhost:8000/唯识宗到禅宗.html>
- 经方全集：<http://localhost:8000/伤寒金匮方剂全集.html>

## 功能特性

### 1. 主题切换

支持三种阅读主题：

- **日间**（默认）：米色背景，柔和护眼
- **羊皮纸**：仿古羊皮纸效果，更具古典质感
- **夜间**：深色背景，适合夜间阅读

> 主题选择会保存在 `localStorage`，下次访问自动恢复。

### 2. 目录导航

- 桌面端：左侧固定侧边栏，可滚动浏览
- 移动端：右下角浮动按钮 ☰，点击弹出全屏抽屉
- 自动高亮：滚动时自动高亮当前阅读章节

### 3. 关键词加粗

- **唯识宗到禅宗** 文件中的关键概念（如阿赖耶识、种子、转识成智等）已规范化加粗
- 加粗规则基于原文（DeepSeek 对话）截图分析后规范

### 4. 阅读体验

- 楷体字体 + 1.85-1.95 行高，符合中文古籍阅读习惯
- 段落首行缩进 2em
- 章节标题（h2/h3/h4）有清晰的视觉层级
- 滚动锚点定位 + 平滑过渡

## 移动端适配

针对手机端做了全面优化：

| 断点 | 适配内容 |
|------|---------|
| **≤ 1080px** | 隐藏桌面端侧边栏，显示浮动按钮 |
| **≤ 768px** | 紧凑化顶部导航，缩小字体，调整内边距 |
| **≤ 420px** | 进一步压缩小屏（如 iPhone SE）的显示 |

**移动端专属特性**：

- 右下角圆形浮动按钮（FAB）打开目录抽屉
- 抽屉支持点击遮罩 / 链接 / ESC 关闭
- 主题按钮在小屏下自动缩小
- 章节标题字号自动调整避免折行

## 主题切换

切换主题的方法：

1. 顶部导航栏右侧的主题按钮（日间 / 羊皮纸 / 夜间）
2. 主题选择会保存在 `localStorage.theme`
3. 重新打开页面时自动应用上次选择的主题

主题通过 CSS 变量实现：

```css
:root { --bg-color: #F7F5EB; --text-color: #2C2C2C; }
[data-theme="dark"] { --bg-color: #1A1A1A; --text-color: #E8E6E1; }
[data-theme="sepia"] { --bg-color: #F4ECD8; --text-color: #3D3326; }
```

## 维护工具

项目目录下的 Python 脚本用于内容处理：

| 脚本 | 用途 |
|------|------|
| `extract_docx.py` | 从 docx 源文件提取内容到 HTML |
| `normalize_bold.py` | 规范化加粗规则（按原文截图） |
| `analyze.py` | 文本结构分析 |
| `process_bold.py` / `process_bold_v2.py` | 加粗规则的不同实现版本 |
| `list_paragraphs.py` / `dump_paragraphs.py` | 段落提取与排版 |
| `paragraphs.txt` | 提取出的段落文本 |

> 这些脚本是处理原始 docx → HTML 工作流的一部分，可重复执行。
